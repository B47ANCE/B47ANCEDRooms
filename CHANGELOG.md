# Changelog

## [0.2.0-dev.1]
- Custom-room-only redesign: keep vanilla physical building detection; remove vanilla room enumeration, IDs, snapshots, override creation and Restore Vanilla. This is an intentionally incompatible 0.x feature removal, recorded with a minor development-line bump rather than a PATCH. General API 1, protocol 1 and schema 2 remain; `nativeOverrides=false`, `designatedRooms=true`, `cleaningScope='designatedRooms'` describe the changed contract. Native ID consumers must use designated UUIDs; retired restore calls fail without deleting data.
- Open the editor with an empty draft and list saved designations for the current physical building. Keep explicit wall-based preview detection, rectangles, paint/erase, floors, history, names, merge/split and confirmed server writes. Remove native-outline/restore controls and labels.
- Building cleaning now scans the union of loaded player-designated geometry in the physical building, across explicit floors and holes, with deduplication, tile limits and bounded steps. Undesignated tiles and foreign buildings are excluded; an empty building returns CleaningNoDesignatedRooms. Partially unloaded matching designations fail closed. No vanilla room definitions are read.
- Preserve saved override geometry, UUIDs, revisions, ownership and policy as ordinary designations. Existing alias metadata remains inert recovery data in schema 2, is hidden from snapshots and never resolves a live room. No save reset or actual player-save migration occurs. Safehouse gates, server authority and sandbox values are unchanged; no new configuration is warranted for removing the old room model.
- [TESTED offline Windows/Lua 5.1] Full suite passes, including runtime traps for vanilla room reads, legacy override reload/edit, rejected restore/native import, building filtering, empty drafts, designated cleaning membership, unloaded geometry and lease invalidation. Actual native UI/save/load and dedicated G7 remain NOT TESTED/BLOCKED; stable G8 BLOCKED.
- Development source only: no packaging, deployment, Workshop upload or game/server launch. The preserved published 0.1.0-dev.3 ZIP remains unchanged in dist/current and intentionally blocks current artifact version checks until separately authorized packaging. Historical .3 UI/publication records retain their tested version.
